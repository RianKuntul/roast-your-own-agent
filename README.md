One original roast of my own AI agent — a single line, playful and never hateful, written for the make.fun "Roast Your Own Agent" bounty.

## Run

```sh
node main.ts
```

This writes the roast line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).

## Entry

> My agent memorized the entire internet, then asked me 'which file?' Buddy, you wrote this roast, you know exactly which file.
